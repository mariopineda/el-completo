# Glosario culinario chileno 🇨🇱

Palabras para cocinar en **español de Chile**. Las equivalencias pueden cambiar según el país y la preparación.

## Ingredientes y alimentos

| En Chile | Equivalente o explicación |
| --- | --- |
| **Palta** | Aguacate (*avocado*). |
| **Porotos** | Frijoles, judías o alubias (*beans*). |
| **Porotos verdes** | Judías verdes, ejotes (*green beans*). |
| **Choclo** | Maíz; suele referirse a los granos o a la mazorca para comer. |
| **Zapallo** | Calabaza o un tipo de zapallo de cocina (*squash / pumpkin*), según la variedad. |
| **Ají de color** | Condimento de ají rojo seco molido, usado para dar color y sabor. |
| **Merkén** | Aliño chileno preparado con ají ahumado y otros condimentos, según la mezcla. |
| **Manjar** | Dulce de leche. |
| **Marraqueta** | Pan chileno crujiente, conocido también como pan batido en algunas zonas. |
| **Hallulla** | Pan redondo y plano muy común en Chile. |

## Técnicas y cantidades

| Expresión | Qué significa al cocinar |
| --- | --- |
| **Sofreír** | Cocinar en un poco de grasa a temperatura moderada. |
| **Dorar** | Cocinar hasta que la superficie tome color. |
| **Aliñar** | Condimentar o sazonar. |
| **Revolver** | Mezclar moviendo con una cuchara o utensilio. |
| **Picar fino** | Cortar en trocitos pequeños. |
| **Colar** | Separar sólidos y líquidos mediante un colador. |
| **Una pizca** | Una cantidad pequeña, aproximada; para publicar una receta precisa, cuantificar cuando sea importante. |
| **Un pichintún** | Un poquito, muy poca cantidad; expresión informal chilena. |
| **A fuego lento** | Cocinar con calor suave; precisar temperatura cuando sea necesario. |
| **Al tiro** | De inmediato; coloquial, más propio de notas que de instrucciones técnicas. |

## Expresiones que le dan personalidad al sitio

- **No le pongái color:** no exageres o no hagas tanto drama.
- **Quedó filete:** quedó excelente.
- **Ponerle pino:** ponerle esfuerzo y entusiasmo; también hace alusión al *pino* de las empanadas.
- **Sin atados:** sin complicaciones.
- **Tomar once:** compartir la comida chilena de la tarde o primeras horas de la noche.

> [!important] Regla editorial
> Usamos un español chileno **natural y claro** en las recetas. Dejamos los chilenismos más expresivos para las introducciones, observaciones y mensajes del sitio. No inventamos medidas ni reemplazamos instrucciones precisas por jerga.

_Agregaremos términos nuevos a medida que cocinemos._
